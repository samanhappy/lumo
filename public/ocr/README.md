# OCR language data

Unmodified gzip-compressed int8 LSTM models from the official Tesseract.js language packages:

- `chi_sim.traineddata.gz`: `@tesseract.js-data/chi_sim@1.0.0/4.0.0_best_int/chi_sim.traineddata.gz`
- `eng.traineddata.gz`: `@tesseract.js-data/eng@1.0.0/4.0.0_best_int/eng.traineddata.gz`

Source: https://github.com/naptha/tessdata
Underlying Tesseract language data: https://github.com/tesseract-ocr/tessdata_best (Apache License 2.0).

Served locally to the browser; no third-party OCR service receives user photos.
