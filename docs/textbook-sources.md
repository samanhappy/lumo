## 数据库同步与维护

- `seeds/textbooks/primary-words.js`、`primary-poetry.js`、`primary-english.js` 是本次新增年级导入包；六年级原有文件与词条ID保留。26个旧示例条目保留并标注示例，不计入上述教材数量。
- 运行时从数据库 `textbook_courses` 读取，前端通过 `GET /api/courses` 加载；没有将教材重新打包进浏览器JS。
- 服务器启动或执行 `npm run import:textbooks` 会事务同步缺失课程、单元和词条，并更新课程的收录说明；已有课程名称、单元信息及词条文字保留，不覆盖本地校订内容，也不删除旧内容。重复执行不重复添加。
- 学生学习记录单独保存在 `app_data`，同步不写入学生记录，不改变已有词条ID。不同教材版次使用不同ID；新版本必须重新核对并单独录入，不能覆盖旧版进度。
- 修改已有词条的种子内容不会覆盖数据库校订内容；当前没有教材编辑后台，也没有自动跟踪出版社更新的网络同步任务。
